# Reconstruction roadmap

## Phase 1 — Executable foundation
React, TypeScript, Vite, routing, visual system, Firebase configuration, emulators, rules, Functions workspace and initial domain tests.

## Phase 2 — Identity and authorization
Firebase Auth, custom claims, role guards, user administration and rule tests.

## Phase 3 — Catalog and dining room
Firestore repositories, product images, categories, tables and seed data.

## Phase 4 — Ordering and kitchen
Transactional order flow, kitchen tickets, real-time station boards and state-transition tests.

## Phase 5 — Fulfillment and reporting
Delivery, returns, cancellations, closure Function, audit events and basic reports.

## Phase 6 — Hardening
E2E tests, emulator integration, CI, accessibility, performance, error handling and DEV deployment.

## Phase 7 — Documentation and study
C4 diagrams, ADRs, module guides, security model, test matrix and defense questions.
