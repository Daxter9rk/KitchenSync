# KitchenSync

Sistema web para gestión de comandas en restaurante.

## Funcionalidades
- Gestión de mesas
- Envío de pedidos a cocina por estación
- Seguimiento en tiempo real (pendiente, preparando, listo)
- Control de entregas, devoluciones y cancelaciones
- Historial de pedidos con exportación a PDF

## Tecnologías
- HTML
- CSS
- JavaScript (Vanilla)

## Objetivo
Optimizar el flujo de pedidos entre meseros y cocina.
